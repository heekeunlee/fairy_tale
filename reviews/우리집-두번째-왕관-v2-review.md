# 심사 — 우리 집 두 번째 왕관 (v2)

## 종합 판정: **통과**

v1의 두 지적사항 모두 해결됐다.

1. **절정부 망설임 부족** → 해결. "다온은 이불을 머리끝까지 덮었다가, 다시 살짝 걷어냈어요. 나갈까, 말까."로 구체적인 망설임의 몸짓이 추가됐다.
2. **분량·감각 미달** → 해결. "며칠 뒤 늦은 밤, 온 집 안이 조용했어요"로 밤의 정적을 먼저 깔아 이어지는 울음소리와 대비를 주고, 자장가도 "낮고 부드럽게, 파도처럼 넘실거리던"으로 구체화됐다. 발단부에도 "왕관을 쓴 날은 유치원 가는 것도 신이 났어요"가 더해져 상실의 낙차가 커졌다. 분량은 약 930자.

## 기준별 재평가
- **구성**: 정적→울음의 대비가 위기의 긴장감을 높인다.
- **문체**: 의성어·반복구 모두 정확. 감각 묘사가 v1보다 풍부해졌다.
- **메시지 전달력**: "왕관"이라는 구체적 사물을 시종일관 사용해 설명 없이 완성된다.
- **독창성**: 동생 질투라는 흔한 소재를 "왕관"이라는 하나의 상징으로 시종일관 관철한 점이 이 작품의 힘.

## 잘 된 점
- 왕관이라는 단일 상징의 일관된 사용.
- 정적과 울음의 대비로 긴장감 조성.
- 질투를 나쁜 감정으로 그리지 않는 담담한 처리.
